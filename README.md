# Nexcent Landing Page (Client Portal)

A membership/community management platform landing page, built for a fictional client "Nexcent" as a portfolio project.

## Live Demo
https://client-portal.philipoyewole62.workers.dev/

## Features
- Multi-section marketing site: Home, Services, Features, Product, Testimonials, FAQ
- Login flow
- Client trust/logo showcase
- Testimonial section
- Blog/insights preview section
- Newsletter signup footer

## Tech Stack
HTML5, CSS3

## What I focused on
Building a full-scale SaaS-style marketing site with multiple linked pages (not just a single-page scroll) — practicing site architecture, navigation, and consistent design across sections.
